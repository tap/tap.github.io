## Max

[Max](https://cycling74.com/products/max) is a visual programming language for music, audio, and media. I spent 15 years as a core part of the team designing and building it at Cycling '74 (now part of Ableton).

## Jamoma

[Jamoma](https://jamoma.org) is an open-source project I founded to create a framework for structured, modular patching in Max and other environments. It grew into an international research collaboration spanning multiple universities and institutions.

## Electrotap Products

I founded [Electrotap](https://github.com/electrotap) to create hardware and software for musicians and artists:

- **Teabox** — A sensor interface for connecting physical sensors to computers for interactive music and art. Open-source hardware and software available on [GitHub](https://github.com/electrotap/Teabox).
- **Hipno** — A collection of real-time visual plug-ins built on Jitter, centered around the Hipnoscope interface for intuitive parameter control.
- **TapTools** — A large collection of objects and externals for Max covering audio processing, data manipulation, and utilities.

## 8space

[8space](https://cycling74.com/tools/place-8space) — An 8-in/8-out audio spatialization matrix with graphical location controls and real-time gesture recording, playback, and manipulation.
