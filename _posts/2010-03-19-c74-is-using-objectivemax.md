The [c74 iPhone application](http://www.nr74.org/c74) is a cool app for controlling Max remotely.

The source code was published to the c74 Twitter page @ [http://www.nr74.org/c74](http://www.nr74.org/c74) . The Mac version is using [ObjectiveMax](http://github.com/tap/ObjectiveMax), an open source project that we originally developed for Tap.Tools 3.

Cool stuff!
